    2   MiMo-VL (arXiv:2506.03569)

    2.1   Overview

    架构依然是 ViT Encoder + MLP adapter + LLM 结构

    训练包括 SFT pre-training 和 RL post-training 两个阶段。

    2.2   pre-training

    pre-training 主要在训练数据上做文章，总数据量达到了2.4T，包含

    • general image captions 图片描述
    • interleaved data 交叉数据（图文混合）
    • OCR data 光学字符识别数据
    • grounding data 定位数据
    • video content 视频内容
    • GUI interactions 图形用户界面交互
    • reasoning examples 推理示例
    • text-only sequences 纯文本序列

    四阶段训练如下：

    Stages Stage 1 Stage 2 Stage 3 Stage 4
    Purpose Projector Warmup Vision-Language Alignment Multimodal Pre-training Long-context SFT
    Dataset Image-Caption Pairs + Interleaved Data + Pure Text, OCR, Grounding, QA, Video, GUI, Instruction Data, Reasoning Data + Long Pure Text, Long Documents, High-resolution Images, Extended Videos, Long Reasoning Data
    Learning Rate 1e-3 1e-4, 1e-5 1e-5 2.5e-5
    Training Tokens 300B 16.7B 1.4T 550B
    Sequence Length 8K 8K 8K 32K
    Trainable Components Projector ViT, Projector All All

    在第四阶段引入了长上下文训练

    3   InternVL3 (arXiv:2504.10479)

    一大特点是统一的文本和视觉预训练，声称可以解决对齐问题。

    3.1   Overview

    模型架构依然是ViT-MLP-LLM，LLM和ViT都用预训练的模型初始化

    3.1.0.1   一个小插曲

    MMMU排行榜上InternVL3-8B得分62.7，InternVL3-9B得分 57.7，百思不得其解。
    真正原因是8B模型用Qwen2.5-7B初始化，9B模型用InternLM3-8B初始化。
    不得不说，Qwen NB

    3.2   一些特殊的地方

    3.2.1   pixel unshuffle

    在ViT输入端使用，把一个window的像素重组到channel维度，448*448*3的图像转为224*224*12的图像，之后再划分为14*14的patches，可以减少最终的visual token数量。
    主要用于处理高分辨率图像。

    3.2.2   Variable Visual Position Encoding

    在对文本和图像进行位置编码时使用，对于文本，其position index ，对于视觉token，其position index ，其中是一个小于1的数。
    注意到RoPE中对position index不要求为整数，所以这样可以减小最终的context length。
    这种方法类似拓展上下文的Position Interpolation方法，也是直接对position index进行放缩。

    ⚠️ TODO: 常用的拓展上下文的方法还有YaRN，可以就着RoPE一起学习，嗷嗷还有用于图像的2D-RoPE

    3.2.3   Loss weight average

    在训练next-token-prediction时使用，loss定义如下

    意思是只考虑文本token的预测，只把视觉token看作上下文。
    的选择比较有讲究

    • token average : ，会导致梯度偏向更长的回答，也好理解，回答的token越长，在最终的loss占比就越大
    • sample average : ，会导致梯度偏向更短的回答。这里的指的就是回答的长度，这会导致梯度偏向更短的回答。可能原因是这个对长回答的缩小权重太大了。
    • square average : ，本文提出的方法

    3.2.4   Mixed Preference Optimization

    给正负样本对，学习preference，不同于上一篇，这里的正负样本对是预先生成好的数据。

    • 对于有明确答案的样本，正确的为正样本。不匹配以及没有提供答案的为负样本。
    • 对于没有明确答案的样本，将模型生成的回答作为正样本。之后将正样本截断一半，让模型在不输入图像的情况下补全剩下一半，作为负样本。
      • 虽然原模型给出的正样本不一定完全正确，但是也符合比负样本好的偏序关系。

    3.2.5   Test-Time Scaling

    训练了一个奖励模型进行过程级的打分，生成时用Best-of-N策略。
    但是并没有用强化学习进行CoT的训练。

    4   Seed1.5-VL (arXiv:2505.07062)

    一篇很rich的技术报告

    4.1   Vision Encoder

    4.1.1   Architecture

    从头训了一个ViT，从而原生支持多分辨率的视觉输入，而不是微调一个预训练好的固定分辨率的encoder。使用的是2D-RoPE，这个后续可以进一步学习。
    这里在输入MLP前对embedding进行pooling，从而减少token数量。和InternVL3的pixel unshuffle不一样，后者在输入ViT前就进行处理。

    4.1.2   Pretrain

    三阶段预训练这个ViT Encoder，结果是在zero-shot的分类任务上效果比较好。

    • MIM with 2D RoPE
      • mask掉输入图像75%的patch和RoPE embeddings，最小化teacher model(EVA02-CLIP-E)和student model在masked patch上clip feature的cos相似度。
      • ⚠️ TODO: 这里在写作时一直强调visual position embedding的方法，看起来是比较关键的，后续研究研究
    • Native-Resolution Contrastive Learning
      • text encoder用的是预训练的(EVA02-CLIP-E)，使用SigLIP loss和SuperClass loss
    • Omni-modal Pre-training
      • 对齐视频数据中video frames, audio, visual captions, and audio captions，期望学习一个unified的视觉表示。

    4.1.3   Video-Encoding

    时间维度上，根据复杂度动态调整FPS，空间上，动态调整分辨率，保证一个视频最多81920 tokens

    4.2   Pre-training

    4.2.1   Data

    4.2.1.1   Image-Text Pair

    收集来的数据具有长尾效应，通过实验得出：对于常见的类别需要保持丰富的样本，对于不常见的类别需要有充足的训练次数(iteration)。

    因此对Image-Text Pair数据一些不常见的domain进行了复制。

    4.2.1.2   Optical Character Recognition (OCR)

    • document
      • 先从收集到的页面中提取内容和布局信息，之后用SynthDog or LaTex改文字
      • 用模糊、失真进行数据增强，模拟实际场景下文档图片不对齐的情况。
    • chart
      • LLM生成文本内容 + LLM转为LaTex or Python代码 + 渲染出图
    • table
      • 直接收集 HTML or LaTex or Markdown 格式的表格
      • 不知道为什么没有进行增强，我理解和chart是类似的

    4.2.1.3   Visual Grounding & Counting

    这俩其实是一类任务，只有学会了grounding才能count

    • Bounding Box Data
      • 主要任务
        • 通用的二维定位任务
        • 空间关系的QA
        • 视觉prompt输入的QA
      • 数据来源
        • 现有数据集：Objects365 + OpenImages + RefCOCO/+/g
        • Grounding DINO合成
      • 量级
        • 48M samples and 41B tokens + 200M samples and 200B tokens
    • Point Data
      • 主要任务：要输入物体的中心点位置
      • 数据来源
        • 现有数据集：PixMo-Points
        • Molmo + CountGD 合成
      • 量级
        • 170M instructions and 110B tokens
    • Counting Data
      • 从上面俩数据集可以直接构建count任务的数据集
      • 量级
        • 8M samples and 13B tokens

    4.2.1.4   3D Spatial Understanding

    • 主要任务
      • relative depth sorting
      • absolute depth estimation
      • 3D grounding

    4.2.1.5   Video

    • 主要任务
      • general video understanding
      • video grounding and moment retrieval
      • video streaming data
        • Interleaved Caption/QA Data
        • Proactive Reasoning Data：需要模型主动决定回答的时刻
        • Realtime Commentary Data

    4.2.1.6   Science, Technology, Engineering, and Mathematics (STEM)

    主要涉及理科任务的解决，包括专业图像的理解，和解题能力。

    4.2.1.7   Graphical User Interface (GUI)

    perception + grounding + reasoning

    4.2.2   Train

    三阶段组成

    • stage0: only MLP
      • 实验中发现stage0同时训练encoder和mlp不如只训练mlp，可能原因是最开始LLM被冻结，能力不足，所以encoder需要对此做出补偿，损害了其感知能力（我个人感觉就是llm没有训练，传回来的梯度就很奇怪，而预训练好的encoder能力很强，又比较 Fragile && Delicate）
    • stage1: full
      • 主要是基础的感知任务
      • captions, interleaved image-text, visual grounding, and OCR data
      • 加入少量纯文本以及指令遵循数据会更好
    • stage2: full
      • 增加了上下文长度，从32768到131072
      • 增加了更复杂的任务，video understanding, coding, and 3D spatial understanding

    4.3   Post-training

    The post-training stage equips Seed1.5-VL with robust instruction-following and reasoning abilities through a combination of Supervised Fine-tuning (SFT) and Reinforcement Learning (RL)

    后训练的目的就是提高指令遵循和推理能力

    4.3.1   Supervised Fine-tuning (SFT)

    The Supervised Fine-tuning (SFT) stage is integral to equipping Seed1.5-VL with foundational instructionfollowing and reasoning capabilities prior to reinforcement learning.

    SFT阶段主要起到冷启动的作用。

    4.3.1.1   Data

    数据也需要从General Instruction Following和Long Chain-of-Thought入手。

    相较于预训练，这里的数据量小很多，共50K samples，但是要求覆盖范围广以及高质量。

    • 覆盖范围广：对任务进行分类，根据embedding model将数据聚类，保持一个较高的丰富性
    • 高质量
      • 一个好的cold start model会让后续RL效果更好，所以采取逐轮迭代的训练方法。即SFT后先进行一次RL，用得到的model进行rollout，选出正确的、好的结果增加到SFT data中，再进行SFT，如此反复。

    相较于直接人力标注，这种优化模型输出的数据收集方式更高效，也排除了超出模型能力的数据，减轻了幻觉。

    4.3.2   Reinforcement Learning from Human Feedback

    RLHF遵循 收集偏好数据 -> 训练奖励模型 -> 强化学习 的流程。

    4.3.2.1   偏好数据

    偏好数据主要来自人类标注+合成

    • 人类标注
    • 合成
      • 合成数据不容易泛化，reward model可能学习到原回答和编辑回答的模式
      • 这里使用那些有标准回答的问题，并限制了回答的模式，根据结果是否正确以及是否遵守格式进行打分

    4.3.2.2   奖励模型

    训练时需要排除输入顺序对输出的影响，方法就是先输入再输入。

    4.3.2.3   强化学习

    这里有两个数据的概念，一个是前面用于训练奖励模型的数据，一个是这里用于训练VLM的prompt

    后者需要反映前者的分布，但是实际数据在难度和所需能力上分布不均，有几种筛选方法

    • 用一个tag model去标注prompt所需的能力
    • 对每个prompt，先rollout多个回答，让reward model打分，reward差别不大的，说明reward model区分不出来，就删掉
    • 在训练时，根据reward 和 KL散度删除过于简单的prompt

    4.3.3   Reinforcement Learning with Verifiable Rewards

    • Visual STEM：主要是一些有标答的数学题
      • 把选择题改成大题，防止模型瞎猜
      • 不能太难 or 太简单
      • 不能只凭文本就能答对
    • Visual Perception and Reasoning：这些视觉任务也都是可以直接评判的
      • Grounding
      • Visual Instruction Following
      • Visual Puzzles & Games
